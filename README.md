# Typing Samurai 🥷

A Python-based typing game inspired by Japanese culture.

Play it on itch.io: https://white-lama.itch.io/samurai-typing

## About the Game

Typing Samurai is a small desktop typing game developed using Python and Pygame.

Players help a samurai travel through different locations by typing Japanese-related English words and sentences correctly before time runs out.

## Features

- Two difficulty levels:
  - Beginner: 25 words, 60 seconds
  - Pro: 15 sentences, 120 seconds
- Lives system
- Typing accuracy checking
- Randomized questions
- Animated samurai characters
- Multiple game endings depending on performance
